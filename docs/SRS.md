## 1. 目的与需求依据

本文件将本轮产品讨论整理为可评审、可追踪和可验收的需求。产品面向需要临时高速文件空间的 Windows 用户，在创建磁盘时预分配全部非分页数据内存，通过普通盘符或挂载目录访问，支持 NTFS 和 exFAT。

本文件区分三类内容：

- **已确认约束**：用户明确提出或选择的要求，见第 2 节。
- **首版建议需求**：为形成完整产品而补充的功能、异常行为和质量要求；随本文件一并等待确认。
- **待决事项**：影响范围、实现或验收，但尚未确定的选择，见第 13 节。不得将其视为已获批准。

本阶段仅确认需求，不授权部署、驱动安装或对真实磁盘执行操作。

## 3. 范围与术语

### 3.1 首版建议范围

首版包含多磁盘管理、创建时固定容量预分配、NTFS/exFAT 格式化、挂载与安全卸载、显式销毁、CLI、GUI、实时性能监控、容量与内存统计、基础文件级基准测试、事件诊断，以及安装和卸载。

首版不包含盘内数据镜像保存与恢复、跨重启数据恢复、快照与克隆、内存压缩、按需分配、动态回收、在线扩缩容、自研文件系统、跨平台和自动更新。

### 3.2 术语

| 术语 | 定义 |
| --- | --- |
| 磁盘实例 | 由驱动管理、具有唯一实例标识的内存磁盘及其数据内存。 |
| 逻辑容量 | 对系统报告的数据存储容量，不等于文件系统可用空间。 |
| 预分配数据区 | 创建阶段已完整申请、存活期间保持占用的非分页内存。 |
| 额外开销 | 页映射、设备对象、请求上下文、统计及其他管理资源。 |
| 卸载 | 安全解除文件系统使用及访问入口，保留实例和数据，可重新挂载。 |
| 销毁 | 移除实例并释放其资源，盘内数据随之丢弃。 |
| 无需持久化 | 不提供盘内数据的主动保存与恢复；不自动等价于任何系统机制下数据都绝不落盘。 |

## 4. 组件与外部接口

### 4.1 交付组件

文件名为建议名，不限制后续命名调整。

| 组件 | 建议名称 | 职责 |
| --- | --- | --- |
| 内核驱动 | `memdisk.sys` | 非分页内存管理、虚拟块设备、I/O、设备生命周期和统计。 |
| 管理服务 | `memdisk-service.exe` | 权限校验、配置、驱动控制、格式化与挂载协调、诊断与采样。 |
| 命令行工具 | `memdisk.exe` | 管理操作、状态查询、脚本调用与结构化输出。 |
| 图形界面 | `memdisk-ui.exe` | 磁盘管理、性能观察、基准测试与事件诊断。 |
| 安装包 | `memdisk-setup.exe` 或 `.msi` | 驱动和服务安装、升级、卸载与失败回滚。 |

驱动交付同时包含 INF 和签名目录 CAT。调试符号 PDB 按发布版本归档；是否公开分发另行决定。

### 4.2 接口原则

- GUI 与 CLI 通过经过身份校验的本地 IPC 调用管理服务。
- 服务通过受访问控制保护的驱动管理接口执行管理操作。
- 应用文件 I/O 通过 Windows 文件系统和存储栈到达驱动，不经过 GUI 或管理服务转发。
- 复用 Windows 原生 NTFS/exFAT 实现和格式化能力，不自行构造两种文件系统的完整实现。
- 管理协议应具有版本、实例 ID、请求 ID、明确状态和错误码；协议不兼容时明确报错。
- 具体驱动框架、IPC 机制和格式化接口属于设计阶段决策。

## 5. 磁盘与内存功能需求

### 5.1 创建与内存分配

| 编号 | 需求 |
| --- | --- |
| MEM-01 | 创建参数至少包括容量、文件系统、卷标和访问入口；支持自动选择盘符。 |
| MEM-02 | 磁盘对系统可见之前，必须完成全部数据区非分页内存分配及清零。 |
| MEM-03 | 全额预分配允许内部使用多个分配单元或页列表，不要求全部内存在物理地址上连续。不得在后续写入时才补充分配数据区。 |
| MEM-04 | 任一数据区分配失败，整个创建操作失败并释放已分配资源，不得发布容量未获得保障的磁盘。 |
| MEM-05 | 按 C-15，在创建前检查请求容量不超过当前可用物理内存的 80%，不设固定单盘及总容量上限。内存可用量检查只提供预判，实际分配结果决定创建成功与否。 |
| MEM-06 | 磁盘存在期间数据区保持全额占用；删除文件、快速格式化或卸载不归还数据区内存。 |
| MEM-07 | 内存紧张时不得淘汰、覆盖或静默丢弃已成功写入的数据。 |
| MEM-08 | 显示逻辑容量、文件空间、数据区预留、可核算额外开销和总占用，注明各统计口径。 |
| MEM-09 | 首版固定容量；更改容量通过销毁并重建实现，明确会丢失原数据。 |
| MEM-10 | 请求上下文、队列和统计资源具有边界；预分配数据区不等于所有辅助资源都无限可用。辅助分配失败必须安全完成或拒绝请求。 |

### 5.2 文件系统、挂载与管理

| 编号 | 需求 |
| --- | --- |
| DSK-01 | 同时支持多个磁盘实例，每个实例具有不会因盘符变化而改变的唯一实例 ID。 |
| DSK-02 | 创建时可选择 NTFS 或 exFAT，建议默认 NTFS；首版簇大小使用系统默认值。 |
| DSK-03 | 支持列举、查看详情、创建、挂载、安全卸载和销毁；支持设置卷标。 |
| DSK-04 | 格式化前确认目标属于本产品管理的准确实例，不得仅凭可复用的盘符定位目标。 |
| DSK-05 | 盘符冲突、挂载目录不满足条件、格式化失败、权限不足时，返回具体原因并执行约定回滚。 |
| DSK-06 | 创建过程展示分配、清零、初始化、格式化、挂载阶段及耗时；无法准确测量进度时不得伪造百分比。 |
| DSK-07 | 取消操作只在能够安全回滚的阶段生效；取消后清理全部已创建资源。暂不能取消的阶段明确提示。 |
| DSK-08 | 更换文件系统采用销毁重建流程；首版不承诺原地无损转换。 |
| DSK-09 | 安全卸载失败时保留实例和数据，显示占用或系统拒绝原因。首版不提供强制销毁入口。 |
| DSK-10 | 销毁为破坏性操作，确认内容包含实例、盘符/挂载点、卷标和已用空间。CLI 以显式参数表达销毁意图。 |
| DSK-11 | exFAT 的文件权限与高级文件语义按系统能力提供，不得承诺 NTFS 等价功能。 |
| DSK-12 | 安全销毁依次协调卸载、停止新请求、排空或取消在途请求、移除设备和释放内存。存在占用或状态冲突时不得释放仍被使用的资源。 |

### 5.3 生命周期与异常

| 编号 | 需求 |
| --- | --- |
| LIFE-01 | GUI 退出不销毁磁盘，不停止维持磁盘所必需的服务或驱动。 |
| LIFE-02 | 服务重启后重新枚举驱动中现有实例，不因服务控制面重启而主动丢弃磁盘数据。 |
| LIFE-03 | 正常重启或关机后不恢复盘内数据；新创建实例为空盘。 |
| LIFE-04 | 正常睡眠及恢复不得主动重建磁盘，应验证恢复后的数据和设备状态。休眠支持与落盘边界待确认。 |
| LIFE-05 | 创建失败执行事务式回滚，清理可清理的资源；清理失败时记录可追踪的残留状态并允许后续重试，不能静默报告成功。 |
| LIFE-06 | 同一实例的挂载、卸载、销毁等操作串行协调；重复请求得到可解释的结果，不产生重复设备或重复释放。 |
| LIFE-07 | 驱动存在活动实例时，不允许通过普通卸载流程直接移除驱动。 |
| LIFE-08 | 配置是否持久保存、是否开机重建空盘均为待决项；即使保存配置，也不保存用户盘内数据。 |

实例可见状态至少包括：创建中、格式化中、已挂载、卸载中、已卸载、销毁中、失败。操作失败后应回到准确的可恢复状态，不能简单将所有异常实例视为已销毁。

## 6. 数据正确性与设备兼容

| 编号 | 需求 |
| --- | --- |
| IO-01 | 后续读取应符合成功完成写入的可见性与顺序语义；重叠并发 I/O 的保证遵循并明确声明的存储协议语义。 |
| IO-02 | 在格式化写入前，未写入的数据区域读取为零，不能暴露其他分配中的旧数据。 |
| IO-03 | 检查偏移、长度、对齐、越界及整数溢出；错误请求不得破坏数据、泄露内存或导致系统崩溃。 |
| IO-04 | 明确扇区大小、容量、最大传输限制及支持的设备能力；仅报告实际实现的能力。 |
| IO-05 | 正确实现所需 Flush/同步请求的顺序和完成语义；无需持久化不作为忽略请求完成语义的理由。 |
| IO-06 | 请求取消、设备移除、并发卸载不得发生重复完成、死锁、释放后访问和越界访问。 |
| IO-07 | 对不支持的命令返回正确失败状态，不伪装成功。 |
| IO-08 | 不依赖 TRIM 释放预分配内存；是否支持 TRIM 及相应读取语义由设计阶段定义，并与报告能力一致。 |
| IO-09 | 验证普通文件操作、文件锁、内存映射、大文件、杀毒扫描及选择的真实目标工作负载。 |

## 8. 性能监控需求

### 8.1 指标与口径

| 编号 | 指标 | 定义与展示 |
| --- | --- | --- |
| MON-01 | 设备读写吞吐量 | 采样间隔内成功完成的读/写字节数除以实际时间间隔，分别展示。 |
| MON-02 | 设备读写 IOPS | 每秒成功完成的块请求数，区分读与写；不能用字节数反推。 |
| MON-03 | 请求延迟 | 驱动接收至完成的时间，按采样区间统计 P50/P95/P99，明确不是应用端延迟。 |
| MON-04 | 在途请求 | 当前尚未完成的请求数及区间峰值，不与配置并发度混淆。 |
| MON-05 | 累计量 | 当前实例创建以来的读写字节数、请求数、失败数及取消数。 |
| MON-06 | 请求大小分布 | 读写分别统计，作为性能详情展示。 |
| MON-07 | 内存与容量 | 分别显示文件空间、预留数据区和额外开销；文件空间查询慢于设备采样。 |
| MON-08 | 采集状态 | 展示连接、最近有效更新时间、暂停/历史状态和统计口径。 |

应用读取可能命中系统缓存，因此设备吞吐量不得直接标为应用文件访问量。无有效请求的窗口，延迟展示“—”；没有测量到的数据不能伪装为零。

### 8.2 采集与图表

| 编号 | 需求 |
| --- | --- |
| MON-09 | 建议默认设备采样间隔 250 ms，文件空间查询 1 s；按真实经过时间计算速率。最终采样范围及开销预算待确认。 |
| MON-10 | 默认查看最近 60 s，可切换 5 min、30 min；历史缓冲有界，保存窗口与聚合分辨率明确。 |
| MON-11 | 图表支持联动时间轴、悬停游标、缩放和平移；提供返回实时和重置缩放。 |
| MON-12 | 支持框选时间区间，查看区间传输量、请求数、平均吞吐量与可获得的延迟分布。 |
| MON-13 | 点击图例显隐序列；读取/写入的颜色与文字标识在各视图中保持一致。 |
| MON-14 | 多盘聚合分位数合并分布计算，不平均各盘 P99；缺少数据时标注不完整。 |
| MON-15 | 冻结查看只停止视图跟随，后台继续采集；窗口最小化停止无必要绘制。 |
| MON-16 | 断连和丢样形成明确缺口并提示原因；重连或计数器重置不得产生负吞吐或巨大伪峰值。 |
| MON-17 | 事件可标注在时间轴并跳转到相应区间；区间已过期时明确提示。 |
| MON-18 | 用户可主动导出选中区间 CSV；普通监控不自动保存历史性能数据。 |
| MON-19 | 驱动使用有界计数器与延迟直方图等机制，默认不把每次 I/O 完整事件逐条发送到 UI。 |
| MON-20 | 降采样应保留区间峰值/极值信息并注明聚合方式；分位数窗口和直方图精度可解释。 |

## 9. 基准测试需求

| 编号 | 需求 |
| --- | --- |
| BEN-01 | 首版提供顺序读、顺序写、随机读、随机写及混合负载预设，允许设置块大小、并发度、测试大小及持续时间。 |
| BEN-02 | 仅操作目标实例上的专用测试文件，不直接覆写卷或用户文件；测试文件具有唯一命名并按安全规则清理。 |
| BEN-03 | 提供启动、进度和停止；空间不足、卸载冲突、权限不足时给出明确原因。 |
| BEN-04 | 结果记录目标实例、文件系统、块大小、并发度、工作集大小、时间和缓存模式。缓存与绕过系统文件缓存的结果明确区分。 |
| BEN-05 | 结果展示应用端吞吐量、IOPS、延迟分位数与数据校验状态；与设备层监控指标分开命名。 |
| BEN-06 | 绕过缓存时遵守系统对齐要求；预热、准备数据和正式计时区间区分。随机数据可复现，避免读取未初始化测试内容。 |
| BEN-07 | 测试期间阻止冲突管理操作或先安全停止测试；失败和取消也清理可安全清理的测试文件。 |
| BEN-08 | 提供可选读写数据校验；校验是否处于计时区间在结果中说明。 |
| BEN-09 | 性能结论以测量为准，不预设一定优于系统热缓存，不将原型模拟值作为产品承诺。 |

## 10. 安全、诊断与交付

| 编号 | 需求 |
| --- | --- |
| SEC-01 | 创建、格式化、卸载和销毁需要明确管理权限；服务根据请求者身份授权，不信任 GUI 提交的角色声明。 |
| SEC-02 | 驱动接口限制访问并校验输入；管理接口不得允许任意内核内存读写或任意系统磁盘格式化。 |
| SEC-03 | 首版建议仅管理员可修改磁盘实例；普通用户对盘内文件的访问由系统文件系统能力和配置决定。最终多用户模型待确认。 |
| SEC-04 | 日志不记录盘内文件内容、原始数据缓冲或无必要的敏感信息。 |
| SEC-05 | 非分页承诺只约束运行期换页。休眠、系统转储与“绝不落盘”的额外要求需要单独确认，不能隐含承诺。 |
| OPS-01 | 事件包含时间、实例 ID、操作、阶段、结果、耗时、错误码及关联请求 ID。 |
| OPS-02 | 日志具有大小和保留上限；诊断失败不能使磁盘 I/O 失败。日志是否持久写盘待确认。 |
| OPS-03 | UI、CLI 显示可操作的错误信息，保留原始系统错误以便诊断。 |
| OPS-04 | 安装包处理驱动、服务和 GUI/CLI 注册，失败时回滚；检查版本兼容及所需权限。 |
| OPS-05 | 存在活动磁盘时，升级/卸载要求用户先显式处理，不自动销毁数据；清楚提示是否需要重启。 |
| OPS-06 | 发行前完成适用的驱动签名与安全配置兼容验证，并按版本保存二进制、符号和构建标识。 |
| OPS-07 | 首版包含组件许可证与第三方声明。 |

## 11. 非功能需求与建议验收基线

以下数值是本版提出的验收建议，未经确认不视为已承诺的实测能力。

| 编号 | 要求 / 建议基线 |
| --- | --- |
| NFR-01 | 无蓝屏、数据校验错误、越界、重复释放、死锁及跨实例数据泄露。 |
| NFR-02 | 建议持续混合 I/O 压力测试 24 h；正常完成且资源无持续性泄漏。 |
| NFR-03 | 建议执行 1,000 次创建—挂载—I/O—卸载—销毁循环；测试结束无本产品归属的残留实例与未释放分配。 |
| NFR-04 | 低内存与故障注入下，错误可解释、操作可结束、资源可追踪，系统保持响应。 |
| NFR-05 | 受控测试环境中，GUI 普通交互反馈建议不超过 100 ms；长操作及时进入进度状态，不要求任务在 100 ms 内完成。 |
| NFR-06 | 建议覆盖 100%、150%、200% 显示缩放；默认窗口和最小窗口均无关键操作不可访问、文本重叠或严重裁切。 |
| NFR-07 | 建议最小客户区 400 × 600 DIP；可用工作区不足时等比例缩小初始窗口并使用内容滚动。最终值待确认。 |
| NFR-08 | 监控开启/关闭的 CPU、吞吐、尾延迟开销进行对照测量；具体上限在目标硬件及测试条件确定后补齐。 |
| NFR-09 | 不预先承诺统一 GiB/s、IOPS 或微秒延迟；发布指标附硬件、系统、负载、缓存与监控配置。 |
| NFR-10 | Windows 驱动验证工具、系统安全配置和真实工作负载纳入发布检查；工具测试在可恢复测试环境执行。 |
| NFR-11 | CLI 有稳定退出码与机器可读输出；版本不兼容不得静默误解字段。 |
