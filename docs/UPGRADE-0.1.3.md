# 0.1.3：表单对比度与磁盘容量控件

此版本主要更新 GUI，管理协议保持 v1。已有 0.1.2 服务和驱动正常运行时，无需
卸载服务、销毁内存盘或覆盖运行中的程序。

## 更新方式

1. 关闭旧 GUI（不销毁磁盘）。
2. 将 MemDisk-0.1.3-dev-win-x64.zip 解压至新目录。
3. 直接运行新目录中的 memdisk-ui.exe，连接现有服务。

不要把新版 GUI 覆盖到旧包中再使用旧 SHA256SUMS.json 校验，否则旧清单会因
文件变化而拒绝校验。直接从新目录运行可保留两个包各自的完整性清单。

若仍使用更早的服务版本，需要卸载问题修复时请先按 UPGRADE-0.1.2.md 操作。

## 界面变化

- 浅色模式为容量输入框、文件系统下拉框和卷标框提供独立的不透明浅灰背景、
  边框，以及悬停/激活状态。深色模式也有对应的表单层次。
- “我的磁盘”使用可选择的圆角分组控件，显示盘符、卷标、文件系统、状态，
  并展示“已用 / 文件系统总空间”和实际使用比例进度条。
- 容量数据沿用后台每秒采样，UI 线程不新增文件系统查询。
- 悬停容量条可查看磁盘逻辑容量、文件系统总量、可用空间及已用百分比。
- 未挂载或未取得有效采样时显示明确状态，不把未知占用误报为 0%。
- 多盘时磁盘区域有高度上限和滚动，保留下方性能区；缩放时控件跟随可用宽度。

文件系统总空间可能小于磁盘逻辑容量，因此进度条按实际文件系统总空间计算。
删除文件只改变文件空间，不释放预分配的非分页内存。

## VM 检查

浅色模式打开创建对话框，检查三个输入控件正常、悬停和激活时的可见背景与边框。
在已有盘复制和删除文件，等待约一秒，检查已用容量和进度条变化；切换明暗主题、
窗口大小和不同磁盘，确认文字不重叠，卸载后显示未采样状态。
