# 0.1.4：磁盘管理与监控诊断分页

## 界面

- 顶层为“磁盘管理”和“监控诊断”两个标签，启动默认展示磁盘管理。
- 磁盘管理保留创建入口，列表使用该页剩余高度，盘多时在列表内部滚动。
- 每个磁盘控件都有自己的卸载/挂载、销毁和打开目录按钮，操作绑定该控件的实例 ID。
- 销毁确认框也锁定触发按钮对应的实例 ID，不跟随当前选中磁盘变化；目标不可确认时禁止销毁。
- 未挂载磁盘的打开目录按钮禁用；后台操作期间禁用冲突的管理按钮。
- 监控诊断有独立的磁盘选择框，下面保留实时性能、容量内存、基准测试和事件诊断子标签。
- 底部状态栏保持紧凑，完整操作错误在监控诊断的事件诊断中查看。

默认 2:3 窗口比例、自绘窗口、浅色/深色主题和容量进度控件继续保留。

## 更新

本次为 GUI 调整，协议仍是 v1。已有 0.1.2 或更高版本服务正常运行时，只需关闭旧 GUI，
解压 MemDisk-0.1.4-dev-win-x64.zip 到新目录，直接运行新目录中的 memdisk-ui.exe。
不需要销毁磁盘、卸载服务、重新加载驱动或覆盖运行中的文件。

## VM 检查

1. 启动默认进入磁盘管理，没有性能图表堆叠在管理列表下。
2. 创建至少两个盘，分别操作各自的挂载/卸载与打开目录，确认目标正确。
3. 在其中一个盘的控件点击销毁，核对确认框的实例、盘符、卷标，取消后数据不变。
4. 切换监控诊断并选择不同磁盘，查看子标签数据；返回磁盘管理，实例状态保持。
5. 改变窗口大小和主题，检查每个磁盘控件内的按钮均可见，多盘时列表可滚动。
